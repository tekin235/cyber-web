# Cyber Workshop

An immersive, gamified cyber portal and dungeon dashboard with medieval fantasy aesthetics, real-time spatial navigation, interactive trials, audio effects, and modal chambers.

## Features

- **Portal Gateway & Chamber**: Sign-in portal with smooth transition animation and audio effects.
- **Medieval Stone Arch Dungeon Gates**: Handcrafted, scalable vector SVG gates with realistic perspective 3D swing animations.
- **Interactive Trial Chambers**: Modular challenge popups with cipher flag verification, instant demo solves, and audio chimes.
- **Dynamic Stats & Progression**: Live flag counters, chamber clearance trackers, and level EXP progression.
- **Ambient SFX & Music**: Web Audio synthesized chimes and effects with persistent mute toggle.

## Tech Stack

- HTML5 / CSS3 (Custom Glassmorphism, 3D CSS transforms, Vector SVGs)
- Vanilla JavaScript (Event-driven state machine)
- Web Audio API (Synthesized SFX)

## Getting Started

Open `index.html` in any modern web browser or serve locally:

```bash
# Python local server
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
