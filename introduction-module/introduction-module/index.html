The page that shouldn't exist

Waterside Slate · click and inspect as you would on a live target
This is Acme's public site. Before poking around by hand, check what it's telling search engines not to index — every site has this file. Visit /robots.txt
How this works robots.txt is a plain text file websites publish to tell automated crawlers which pages to skip. It's a polite request, not a lock. Developers sometimes list sensitive paths there by mistake, pointing right at what they meant to hide.

The guestbook

Post slate · post a comment, see what happens when it's rendered
Acme's site admin manually reviews every new guestbook comment — you can see that in an old changelog post. Whatever you post here, they will open it. Try posting something and see what the page does with it.
How this works Cross-site scripting (XSS) happens when a site takes user input and renders it directly without sanitizing. If the browser can't distinguish content from executable script, a comment box becomes a weapon to execute code in another user's session.

The Runestone Memo

Decryption Slate · decipher the intercepted ancient Caesar/ROT13 cipher
An encrypted courier note was left in the hollow oak. The letters appear shifted by an ancient cipher. Adjust the Shift slider to 13 (ROT13) to reveal the message.
How this works ROT13 and Caesar ciphers shift each alphabet letter by a fixed position. Because they lack a secret key and have a tiny keyspace (26 positions), they can be broken in seconds.

The Hollow Willow Form

Diagnostics Terminal · form fields piped straight to OS shell execution
This outpost server diagnostic tool pings target hosts without validating input. Inject a shell delimiter: 127.0.0.1; cat flag.txt
How this works Command injection occurs when server-side code executes shell commands using unescaped user input (e.g. system("ping " + host)). Characters like ; or && let you append unauthorized shell commands.

The River Ferry Ledger

Passenger Portal · unauthorized direct object reference via URL parameters
You're viewing your normal passenger ticket #1042. Notice how the URL references the ticket ID directly: ?id=1042. Change the ticket ID to 1001 to inspect the confidential Harbor Master record.
How this works Insecure Direct Object Reference (IDOR) happens when an application accesses database records using user-supplied parameters without verifying whether the user is authorized to access that specific record.

The Mossy Ravine Bridge

Maintenance Viewer · unvalidated file paths escaping the web root
This maintenance portal loads files directly from the filesystem using the file parameter. Use ../ to escape the folder and read system files: ../../../../etc/passwd
How this works Path traversal (dot-dot-slash) vulnerabilities happen when an application uses user-controlled paths with filesystem APIs without sanitizing ../ sequences, letting attackers read arbitrary confidential server files.
