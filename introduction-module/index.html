Module 5 — Cryptography

The Encrypted Memo

Decryption Utility · decipher intercepted Caesar/ROT13 cipher text
An encrypted memo was intercepted in transit. The characters appear shifted by a basic cipher. Adjust the Shift slider to 13 (ROT13) to reveal the message.
How this works ROT13 and Caesar ciphers shift each alphabet letter by a fixed position. Because they lack a secret key and have a tiny keyspace (26 positions), they can be broken in seconds.

Module 6 — Command Injection

System Ping Diagnostics

Diagnostics Terminal · form fields piped straight to OS shell execution
This server diagnostic tool pings target hosts without validating input. Inject a shell delimiter: 127.0.0.1; cat flag.txt
How this works Command injection occurs when server-side code executes shell commands using unescaped user input (e.g. system("ping " + host)). Characters like ; or && let you append unauthorized shell commands.
