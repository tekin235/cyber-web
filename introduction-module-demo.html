CASE 0417 — SCENE 2

The page that shouldn't exist

Fake browser · click and type as you would on a real site
This is Acme's public site. Before poking around by hand, check what it's telling search engines not to index — every site has this file. Visit /robots.txt
How this worksrobots.txt is a plain text file almost every website publishes to tell automated crawlers which pages to skip. It's a request, not a lock — anyone can read it, including people who aren't well-behaved crawlers. Developers sometimes list sensitive paths there by mistake, which points right at what they meant to hide.

CASE 0417 — SCENE 3

The guestbook

Fake browser · post a comment, see what happens when it's read
Acme's site admin manually reviews every new guestbook comment — you can see that in an old changelog post. Whatever you post here, they will open it. Try posting something and see what the page does with it.
How this worksCross-site scripting (XSS) happens when a site takes what someone typed — a comment, a username, a search box — and shows it back on the page without checking it first. If your browser can't tell "content" from "code," a comment box becomes a place to run real code in someone else's browser.
